# M038 — first canonical two-speed lineage result

**Status: canonical positive result. One frozen task, one immutable first run.**

M038 asked whether a bounded organism can leave a compact fast path only when its current
body is provably insufficient, execute one causally journalled metamorphosis, preserve the
valid improvement across a separate failed provisional change, and return to the fast path
while paying less proof cost than full critical-path journalling.

On the one task derived from the frozen arming head, the answer is **yes**.

This is not Gate 2, Gate 9, full lineage replay, migration, multi-cycle plasticity or general
intelligence. The scope is exactly one frozen DFA cycle.

## What M038 has demonstrated

Within one frozen finite domain and one immutable first run, the same organism can:

- operate through a compact fast path;
- diagnose a limitation from its own admitted evidence using an exact certificate;
- enter a separate slow path only when that certificate proves the body insufficient;
- construct and independently validate a larger body;
- adopt an exact improvement;
- survive a distinct failed provisional change through exact rollback;
- resume with the valid improvement preserved;
- produce a causally anchored slow-path record;
- avoid the majority of the proof cost imposed by full critical-path journalling.

This is the first integrated canonical evidence in the repository for the two-speed
organism architecture. It turns several previously separate mechanisms into one continuous
bounded lifecycle.

## What M038 has not demonstrated

M038 does **not** establish:

- autonomous construction of a required internal tool — Gate 2;
- replay of every fast-path micro-operation from seed — level 3;
- three accepted cycles separated by new task families — Gate 9;
- reuse or extension of a tool learned in an earlier cycle;
- complete trans-substrate migration;
- post-migration plasticity;
- superiority outside this finite DFA domain;
- general intelligence or consciousness.

Every available structural symbol was supplied by the frozen protocol. No `ToolConstructed`
event was claimed.

## Stop condition

The protocol stops after this one canonical cycle. The first artifact is not replaced by a
rerun, another seed, a wider budget or a relaxed rule.

Any later execution of the same arming head is reproduction only. Further research must use
a new experiment and a new frozen protocol rather than extending M038 after seeing this
positive result.
