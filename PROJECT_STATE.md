# Mira Genesis — État du projet

## Objectif ultime

Construire une intelligence capable d’apprendre dans un substrat A, de découvrir un substrat B inconnu, d’y construire un nouveau corps, puis d’y transférer ses compétences, sa mémoire et sa plasticité afin de continuer à apprendre sans intervention architecturale humaine.

- M012 : **INCONCLUSIVE — CONTAMINATED**

## Résultat M012b

M012b a validé, sur des cas générés uniquement après création du SHA immuable, la construction autonome de corps natifs depuis un contrat comportemental opaque et des catalogues booléens déclaratifs.

- 36/36 naissances principales exactes ;
- 108/108 exécutions exactes ;
- 12/12 pour chacun des trois catalogues ;
- 12/12 contrôles négatifs rejetés ;
- dix critères préenregistrés passés ;
- contenu scientifique reproduit indépendamment.

SHA évalué : `c60ddc28e3bea8c7c71d615dace4263f5cf3d187`.

## Échec de développement M013d

Le contrôle non canonique de M013d donnait 36/36 à Genesis, mais la baseline fixe sans sondage obtenait 12/36, au-dessus de son plafond préenregistré de 8/36. Aucun cas scellé n’a été généré et aucune validation n’est revendiquée.

Le seuil n’est pas modifié après résultat. M013e préenregistre à la place un critère relatif : Genesis doit dépasser d’au moins 12 migrations la meilleure baseline sans information sémantique vraie.

## Expérience active — M013e

M013e reçoit douze compétences héritées et trois machines à opcodes anonymes, tous dérivés d’une nonce créée seulement lors du premier run `pull_request/opened`.

Genesis devra :

- sonder les opérations dans un budget de 120 appels ;
- identifier exactement les opérations stables utilisées ;
- exclure les opérations instables ;
- déterminer si la machine est fonctionnellement suffisante ;
- construire un corps contenant seulement les identifiants opaques et sa structure ;
- préserver exactement la compétence sans oracle de tâche ni carte d’opcodes.

Les six tests de développement, l’audit anti-fuite et le protocole complet non canonique passent. Aucun cas canonique M013e n’existe encore.

## Non validé

- adaptation à une physique continue ou analogique ;
- transfert d’une méthode d’apprentissage générale ;
- mémoire autobiographique portable ;
- langage cognitif auto-extensible ;
- auto-métamorphose ouverte.

Le but initial demeure inchangé : apprendre dans un corps A, comprendre un substrat B inconnu, y construire un corps, puis y transférer compétence, mémoire et plasticité afin de continuer à apprendre.
