\section{V19: stratified development and prospective G2 generalization}

V19 keeps executable policy code as the editable target but changes the development gate before any new proposer output. The public development corpus becomes stratified:
\begin{itemize}
  \item 13 chronological real A016-prefix replay worlds;
  \item 188 synthetic worlds drawn from previously public calibration, prospective and negative sequences.
\end{itemize}
The total development corpus is 201 worlds. Direct access to \code{view["world\_id"]} is forbidden so that a policy cannot branch on training-world identity.

A candidate is eligible only if it preserves the real stratum with no paired losses while strictly improving the synthetic stratum without increasing represented requests. This prospective condition makes the V18 plateau-only shortcut insufficient.

Four independent GPT-5.6 Sol / High isolated proposer attempts are returned before laboratory feedback. All four pass the mechanical contract and are decision-equivalent across all 201 development worlds:
\begin{itemize}
  \item real stratum: 13 wins, 0 losses, mean core 953 versus 943, requests 0 versus 1;
  \item synthetic stratum: 188 wins, 0 losses, mean core 750.7074 versus 673.1596, requests 2.7074 versus 3.9574.
\end{itemize}
Because their behavior is identical, the frozen lexical source-hash tie break selects one canonical child, SHA-256 \code{69d0d725...5fdf}. The child source is committed before the holdout wrapper is created.
