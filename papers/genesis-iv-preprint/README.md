# Mira Genesis IV preprint

**Working title:** Mira Genesis IV: Bounded Recursive Process Improvement Across Two Successive Generations

This package covers the V14-V20 Dream-replay / real-organism evidence chain.

## Central claim

Under prospectively frozen rules, Genesis produced a bounded two-transition recursive process-improvement chain:

- G0 -> G1: same retained quality, 4 -> 2 hidden observations;
- G1 -> G2: G2 passes a fresh 24-world replay holdout with 24 wins / 0 losses / 0 ties;
- real G1 -> G2: same retained quality, 2 -> 0 hidden observations.

The project calls this **L3-P**, where P means process improvement.

## Explicit non-claims

This package does not claim open-ended RSI, intelligence explosion, AGI, equal-budget recursive quality uplift, broad transfer, fully autonomous model-only self-authorship, independent external replication, or peer review.
