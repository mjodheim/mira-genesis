\section{Artifact-oriented reproduction checklist}
\label{app:repro}
A third party should distinguish verification of the preserved record from a new scientific replication.

\paragraph{Record verification.}
\begin{enumerate}
  \item Checkout the publication anchor with complete Git history; shallow clones can fail history-dependent integrity checks.
  \item Use the canonical Python version recorded by the target milestone.
  \item Verify frozen protocol and bound-apparatus digests before executing a checker.
  \item Run the milestone checker in read-only/recompute mode first.
  \item Where permitted, run the explicit replay mode and compare the stable evidence projection.
  \item For M112, verify generator/input identity, public chronology, sealed payload commitment, reveal digest, and preserved-bank checker recomputation; do not regenerate the qualifying bank and call it a replay.
\end{enumerate}

\paragraph{Independent replication.}
An independent replication would require a third party to implement or audit the mechanism, freeze its own uncontaminated evaluation, and retain the ability to obtain a negative result. No such replication exists at the time of this snapshot.
