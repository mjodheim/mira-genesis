M110's producer and consumer are ``different domains'' in an implementation sense, but the more informative boundary is the producer's reachable feature support. The acquired rule is constrained on rows the producer can present and unconstrained elsewhere. The failure appears when a new carrier makes an unsupported row realizable.

This view avoids treating domain identity as a categorical magic variable. Two carriers can be syntactically different while sharing all relevant failure rows, in which case transfer may be straightforward. Conversely, a small structural change can create a previously impossible row and invalidate an acquired attribution rule. For stateful self-modifying systems, support in the \emph{meta-observation space} may be more informative than task-domain names.

\subsection{M111 is bounded metacognitive machinery, not general metacognition}
M111 can be read as a small metacognitive result: the lineage uses a record of its own successes and failures to identify where its current observation vocabulary is insufficient to determine a decision. That reading is useful only with the boundary intact. The system does not infer a probabilistic confidence estimate, invent a new sensor, or formulate arbitrary experiments. It detects a discrete ambiguity in a frozen vocabulary and allocates one pre-existing probe.

The significance lies in the causal depth. The diagnostic policy is not available to the earlier machinery because its rule language is monotone. A prior acquired operator makes the later diagnostic distinction expressible. Thus a lineage-acquired representational change becomes a prerequisite for a lineage-acquired decision-about-information change. That is a stronger statement than simply adding an uncertainty heuristic by hand.

\subsection{Blind generation is a useful intermediate tier}
M112 illustrates an evidence tier between project-authored fixtures and independent human evaluation. A context-blind generator can remove direct project selection of values and expose distributional assumptions that the project did not notice, while remaining far from independent custody or uncontaminated external evaluation.

That intermediate tier is valuable if described honestly. It can reveal overfitting to authored generators, as P5 demonstrates. It cannot establish human independence, because the project still chooses the contract and the model. It cannot establish training-data independence for a public project unless the model's data provenance makes that possible. And it cannot substitute for independent reproduction because the project still owns the apparatus and the reveal chronology.

\subsection{Implications for evaluation of self-modifying agents}
The experiments suggest five evaluation practices that scale conceptually beyond this substrate:
\begin{enumerate}
  \item \textbf{Name the object that changed.} Separate task skill, interpreter, search procedure, attribution policy, memory policy, and diagnostic policy.
  \item \textbf{Test causal necessity.} Include predecessor reconstruction, ablation, semantic mutation, and built-but-unregistered controls where the system architecture permits them.
  \item \textbf{Measure support.} Record the observation or failure regions on which an acquired meta-rule was constrained, then deliberately test realizable regions outside that support.
  \item \textbf{Separate capacity from selection quality.} A larger hypothesis space or tool set is not itself a performance guarantee.
  \item \textbf{Preserve failed instruments and mixed results.} Otherwise the evaluation machinery can silently adapt to the very results it is supposed to judge.
\end{enumerate}
These are methodological proposals derived from one case study, not claims that the same finite certificates are available in large stochastic agents.

\section{Related work}
\label{sec:related}
\subsection{Self-modifying and self-improving agents}
The G{\"o}del Machine formalized self-referential improvement as a proof-gated rewrite problem \cite{schmidhuber2007godel}. Recent systems instead use empirical evaluators and foundation models to modify agent code or scaffolding. G{\"o}del Agent permits an LLM agent to modify its own logic under a high-level objective \cite{yin2024godelagent}. Self-improving coding agents similarly edit their own implementations and measure benchmark gains \cite{robeyns2025selfimproving}. The Darwin G{\"o}del Machine maintains an archive of self-modified agents and uses open-ended empirical search to improve coding performance \cite{zhang2025dgm}. Hyperagents make both task and meta-level agent programs editable in one self-referential architecture \cite{zhang2026hyperagents}. MetaSkill-Evolve explicitly evolves task skills and meta-skills on two timescales \cite{wang2026metaskill}. Recent surveys describe this space in terms of update targets and feedback signals across model and scaffold components \cite{ren2026survey}.

\genesis differs primarily in objective and scale. It does not seek state-of-the-art benchmark performance and does not use a foundation model inside the tested M107--M111 acquisition machinery. The finite substrate is chosen so that exact state identity, complete function images, reachable-row support, and structural inexpressibility can be measured. The contribution is therefore complementary: a mechanistic case study of what would count as evidence that one acquired meta-level change caused a later one and where that change fails.
