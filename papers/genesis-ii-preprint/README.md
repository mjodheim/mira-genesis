# Genesis II preprint package — proposal

**Status: PROPOSAL. No manuscript, no DOI, nothing submitted.**

This directory holds what a Genesis II publication package *would* contain, so the owner can decide
scope on evidence rather than on a summary. It is downstream of the scientific record in the strict
sense the project uses that phrase: no frozen experiment, protocol, result, checker, threshold or
qualification population is modified by anything here, and none may be.

Genesis I — *A Reproducible Case Study of Causal Cumulative Capability Acquisition in a Persistent
Software Lineage*, DOI `10.5281/zenodo.22067855` — covers M094–M100 and is not rewritten. Its stated
limitation, that the qualified chain lives inside one authored operation family, is where this
package starts.

## Files

| | |
|---|---|
| `SUBMISSION_METADATA.md` | proposed scope, three candidate titles, abstract, primary and secondary claims, limitations, artifacts, the exact snapshot |
| `FIGURES.md` | the figures and tables the paper should carry, each tied to the frozen result it is read from |
| `REPRODUCIBILITY.md` | how a reader replays each milestone, and what must fail |

There is deliberately **no `paper.tex`**. Scope is an editorial decision the owner has not made, and
writing a manuscript against an unapproved scope would put prose ahead of the record.

## The spine of the paper

The result that carries it is not one of the positives. It is M110's measured **harm**: an acquired
machinery improvement that is confidently wrong, and strictly worse than the fresh predecessor it
improved on, on a failure geometry its producer could not present — while its reachable set grows
monotonically throughout.

That dissociation, *capacity rises and competence does not*, is what makes the surrounding positive
results credible rather than selective, and it is what a reader is least likely to have seen before.

## What this package must never do

Report any generality gate as advanced; describe recursive depth three as open-ended or compounding;
claim acceleration; claim independent reproduction, external audit or human independence; or present
a project-authored world as an externally authored one.
