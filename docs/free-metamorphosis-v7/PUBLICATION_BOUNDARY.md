# Free Metamorphosis v7 — publication and security boundary

This file governs what the public `mira-genesis` record may contain about the private-host v7 campaign. It carries forward the fail-closed boundary used for the v4 public record.

## Public by design

The public record may contain policy identifiers; attempt numbers; parent kind and neutral depth; retained-generation numbers; aggregate capability scores and deltas; warning counts; retain/reject/neutral decisions; high-level sanitized hypotheses; changed-path counts; cryptographic commitments; research-memory and strategy digests; deterministic tournament scores when they reveal no hidden evaluator case; claim boundaries and chronology.

## Private by design

Do not copy private host source or complete patches; private implementation paths that reveal structure; proposer bundles containing the private parent; prompts or user data; credentials or environment values; service endpoints or deployment secrets; raw evaluator cases, contracts, labels or case outputs; evaluator implementation or authority tests; raw logs or crash dumps; campaign-state archives; or evaluator container images.

A SHA-256 or tree digest is a provenance commitment, not publication permission for the object it identifies.

## Canonical authority

The private v7 campaign state remains the canonical experimental authority. `mira-genesis` is the sanitized scientific record and cannot mutate, replay or override the private campaign.
