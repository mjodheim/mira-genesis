Emit a JSON object with a single key "machines" whose value is a list of exactly N entries.

Each entry describes one small machine, and is an object with exactly six keys.

"surface" : an object with exactly eight keys describing how the machine is spoken to.
    "kind"            : one of "json_object", "text_line", "packed_digits", "json_array".
    "ok_token"        : a lowercase ASCII word of 2 to 8 characters, letters and digits only,
                        beginning with a letter.
    "error_token"     : another such word, different from "ok_token".
    "field_separator" : one of " ", ":", ",", ";", "|".
    "pair_separator"  : one of "=", "-", "/".
    "action_key"      : a lowercase ASCII name of 2 to 12 characters, letters, digits and
                        underscores, beginning with a letter.
    "argument_key"    : another such name, different from the other two keys.
    "status_key"      : another such name, different from the other two keys.

"cells" : a list of 3 or 4 objects, each with exactly three keys. These are the machine's state.
    "name"    : a lowercase ASCII name of 2 to 12 characters, letters, digits and underscores,
                beginning with a letter.
    "size"    : 2, 3 or 4. The cell holds an integer from 0 to size minus one.
    "initial" : 0, 1, 2 or 3. The value the cell starts in.

"hidden" : a list of 0 or 1 cell positions. A position listed here names a cell that is not
           reported back. Every other cell is reported. Positions count from 0.

"errors" : a list of 1 to 4 lowercase ASCII names, each 2 to 12 characters, letters, digits and
           underscores, beginning with a letter.

"conditional_actions" : a list of 2 or 3 objects. Each is an action that can only be taken when
                        the state satisfies a precondition, so each has a non-empty "guard".

"actions" : a list of 2 or 3 further objects, in the same shape. These may carry a precondition
            or none at all.

An action is an object with exactly five keys.
    "name"        : a lowercase ASCII name as above.
    "arg_size"    : 0, 2, 3 or 4. It is 0 when the action takes no argument. Otherwise it is the
                    number of distinct arguments the action accepts, which are the integers from 0
                    to arg_size minus one.
    "guard"       : a list of objects, each with exactly three keys. In "conditional_actions" the
                    list holds 1 to 3 of them; in "actions" it holds 0 to 3.
                    "cell"     : a cell position, counting from 0.
                    "relation" : one of "eq", "ne", "lt", "ge".
                    "value"    : 0, 1, 2 or 3.
    "effect"      : a list of 1 to 3 objects, each with exactly three keys.
                    "cell"    : a cell position, counting from 0.
                    "mode"    : one of "set", "add", "sub", "arg", "copy".
                    "operand" : 0, 1, 2 or 3. For "copy" it names a cell position. For "arg" it is
                                ignored. Otherwise it is a value.
    "error_index" : 0, 1, 2 or 3. It selects one of the names in "errors".

Every integer above is bounded exactly as stated, so no entry can be outside its range. A position
or a value that lands past the end of the list or the cell it refers to is taken modulo that
length, so it is always meaningful; you do not need to keep track of the sizes you chose.

Produce the entries independently of one another. Do not repeat an entry, and do not produce two
entries that differ only in the names, tokens or separators they use. Vary the surface kind, the
number of cells, their sizes, which of them are hidden, the number of actions, their argument
counts, their preconditions and their effects across the list.

Do not add keys, comments, prose, explanation or any other text: the response must be the JSON
object and nothing else.

You are not told what these machines are for, and you should not guess. Do not attempt to make
them interesting, balanced, adversarial, representative, easy or difficult. Any such attempt would
make the output worse for its purpose.
