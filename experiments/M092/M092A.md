## 3. Semantic refusal taxonomy — and the defect it caught

`RefusalCode` is a 16-entry implementation-independent vocabulary. The state-owned path raises typed
codes directly; the reference path is normalized into the same vocabulary by
`classify_reference_refusal`. Conservation now compares `value == value` **or**
`same code == same code`, never exception classes or messages.

**This immediately found a real conservation defect.** The reference checks stack **arity before
operator validity**: `BINOP nonesuch` on an empty stack raises *"BINOP needs two operands"*. The
state-owned dispatcher resolved the selector first and raised *invalid selector*. Both refused, so
`refused == refused` passed — for **different reasons**, on 15,960 exhaustive cases and 25,533
adversarial ones.

Fixed state-drivenly: each operation declares `minimum_stack_depth`, checked before selector
resolution, so an unregistered selector still has a well-defined arity. A second bug surfaced while
fixing it — `replacing()` dropped the declared arity, leaving sibling selectors inconsistent — and is
also fixed and tested.

`refusal_taxonomy_can_fail` constructs three cases where the two paths diverge, **two of them
refusing for different reasons**, and requires the checker to report a mismatch in every case.

## 4. The stack bound, resolved by proof rather than exercise

No inherited bound was altered. `stack_depth_certificate` proves the condition unreachable:

- every micro-operation increases stack depth by **at most 1**, verified against the reference
  interpreter itself over **41** operation/argument/depth probes, **0** disagreements;
- a body is at most `MAX_BODY_LENGTH = 6` micro-operations, so depth ≤ 6;
- the declared bound is 8, re-derived by dynamic programming over the whole legal body space.

**Max reachable depth 6 < bound 8.** Status recorded as *unreachable by construction under the
inherited legal representation* — **not** as an exercised conservation case. Malformed and
out-of-representation programs are reported separately from the inherited semantic conservation
claim.

## 7. The K1 boundary, re-audited

The audited claim stands unchanged and unstrengthened: *all audited target-neutral non-iterative
extensions preserve the eventual-polynomial invariant; K1 is the smallest **audited** escape from
that closure.* Universal minimality is not claimed.

**Fuel provenance**, `fuel = 256 + 4 · max(|stack|, |slots|, |inputs|, |argument|)`:

- `FUEL_BASE = 256` is `4 × MAX_PROGRAM_LENGTH (64)`, rounded to a power of two. A loop-free program
  cannot execute more steps than it has instructions, so the base carries a four-fold margin over a
  requirement derived from the kernel's own declared limit.
- `FUEL_SLOPE = 4` is the smallest power of two above one — generic linear headroom in operand
  magnitude, the shape any iteration proportional to its input would need.

The magnitude covers every integer available when an operation starts. This matters because a
substrate operation normally receives its semantic operand through the stack, and may receive a
computed value through a slot; an inputs-only rule would silently stop scaling for those cases.

Neither constant was obtained by running a candidate, and **no qualification world was generated or
inspected during this audit**. Demonstrated rather than asserted: `fuel_insensitivity` re-runs the
conservation sweep across `(base, slope)` ∈ {(16,0), (64,1), (256,4), (1024,16), (4096,64)} — two
orders of magnitude on both constants — and obtains **1 distinct result signature**. No result here
depends on the fuel policy.

K1 remains explicitly authored and is **the next remaining ceiling** if M092 eventually succeeds.
Not self-hosting, not substrate independence; neither term may appear in any M092 result.

## Pre-checkpoint review findings

The resumed review reproduced all evidence from a clean tree and then attacked the boundary that
would become irreversible at the M092-A freeze. It found two defects, both corrected before any
checkpoint or qualification existed:

1. **Fuel observed inputs and the call argument, but not stack or slots.** A future substrate
   operation normally receives its semantic operand through the stack, so a large computed operand
   could receive the same budget as zero. The rule now covers the complete integer entry state and
   a regression executes a 1,000-step stack-fed countdown with zero-valued inputs.
2. **The serialized contract was not closed strongly enough.** Negative dimensions, a negative
   declared stack arity, duplicate parameter domains and duplicate primitive identifiers were
   accepted. They now fail with `malformed_state`, selector/plain dispatch must agree with the
   declared argument role, capability vocabularies cannot overlap, and language primitive
   capabilities are checked against the substrate vocabulary before execution.

Neither correction changes `SUBSTRATE_A`'s semantic digest or any conservation outcome. They harden
the lower runtime that the checkpoint will bind. The checkpoint is still not frozen by this
document; it requires its own committed artifact and verifier.

## Weaknesses and failed adversarial attempts

1. **`classify_reference_refusal` reads exception message text.** The reference raises one exception
   type with prose, so normalizing it means matching substrings. This is migration tooling and is
   never applied to the state-owned path, but a reworded reference message would silently reclassify
   — the fallback is a conspicuous `malformed_state`, so it would surface as a mismatch rather than
   pass, but it is a coupling worth knowing about.
2. **Lengths 5–6 remain sampled**, not exhausted — 6.4M and 148M bodies per state. They lie beyond
   the assembly bound, so no *constructible* inherited body is missed, but the interpreter would
   accept them.
3. **The isolation harness rewrites imports** (`from metamorphosis.X` → `from X`) when copying
   modules. The rewrite is mechanical and the copied files are the real ones, but the isolated
   runtime is textually not byte-identical to the repository modules.
4. **Adversarial value coverage is modest** — 9,598 of 200,000 trials produced a value; the rest
   refused.
5. **M092-A provides no evidence about extension.** It registers nothing new, deliberately, and says
   nothing about whether endogenous substrate extension is possible.
6. **The stack bound is proved unreachable, so it is untested behaviour** in both implementations —
   correct to report, but it means that branch has no conservation evidence behind it.

**Failed attempts to break it:** 200,000 randomized bodies above the assembly bound with
parameterized operands found no divergence; the germ invariant was re-checked through the
state-owned path over 11,712 evaluations with no mismatch; sabotaging the legacy host arithmetic
changed nothing; and stripping site-packages and every injected meta-path finder from the isolated
runtime left the substrate executing correctly.
