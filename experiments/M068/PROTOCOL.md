# M068 — open command-language induction

**Status: TARGET BANK FREEZE CANDIDATE; DISCOVERY ENGINE ABSENT.**

## Research question

Can the continuing lineage recover an opaque body's stateful command words without receiving the
descriptor-product grammar that bounded M067, map those words to inherited behaviour using public
observations alone and preserve the behaviour on disjoint hidden evidence?

M068 removes one new handhold only. M067 enumerated named dimensions — frame family, checksum,
opcode, reply offset, endianness and transform. M068 exposes an opaque action alphabet and a maximum
episode length, but no fields, parser skeleton, command templates, semantic action labels or
complete adapter. The admissible interaction language is every word within the declared resource
bound.

## Freeze order

The target runtime, its four-body bank, action alphabet, bounds and this protocol are committed
before the discovery engine exists. The later implementation commit may add a learner and tests but
may not alter the frozen target bytes. `FROZEN_PROTOCOL.json` binds the runtime by LF-normalised
SHA-256 and records the body-bank attestation.

This is temporal separation inside one project, not independent external authorship. A later gate
must source target bodies from independent contributors or external systems.

## Opaque host boundary

The separate Node process exposes three modes:

- `attest` — body handles, opaque action handles, maximum word length, bank commitment and opaque
  body digests;
- `public` — bounded transaction batches available to discovery;
- `hidden` — the same passive body boundary reserved for independent validation.

A transaction supplies one action word and three signed integer argument slots. It returns only an
identifier, an acceptance bit and a numeric observation. The three-slot host envelope is authored
and disclosed; the command language and semantic mapping are not. The runtime imports crypto only
and has no filesystem, network, repository, credential or deployment authority.

## Frozen bounds

- bodies: 4;
- opaque action handles: 8;
- maximum command-word length: 5;
- non-empty words in the complete search language: `8 + 8² + 8³ + 8⁴ + 8⁵ = 37,448`;
- accepted semantic commands per compatible body: 4;
- body transaction cap per batch: 50,000;
- source skills: inherited M048 version-eight `add`, `max`, `mean`, `mul`;
- source public evidence: the existing five M057 observations per skill;
- independent hidden evidence: the existing three disjoint M057 observations per skill.

The generic word space is a resource bound, not a target descriptor grammar. A learner that imports
the four target words, body source or hidden cases fails the experiment.

## Predeclared discovery rule

The later learner must:

1. enumerate the complete non-empty word language in length-then-lexicographic order;
2. use only two frozen public diagnostic argument triples to find accepted words and distinguish
   behavioural profiles;
3. derive skill targets by observing the inherited source body, never by calculating from names;
4. retain every public-equivalent word-to-skill mapping;
5. send the whole public class to a separate hidden-validation call;
6. select a representation by digest only if every public survivor passes hidden validation.

No hidden-case parameter may appear in the discovery API.

## Required controls

- the first four action handles in declaration order do not form an adapter;
- lexically assigning accepted words to sorted skill names fails at least one public case for every
  body;
- an empty transcript produces no adapter;
- one corrupted source observation produces no complete semantic mapping;
- an action handle outside the attested alphabet is rejected;
- a non-command word is rejected;
- mutating two discovered skill assignments fails hidden validation;
- source inspection of the target runtime is absent from the learner and unnecessary for replay.

## Decision rule and claim boundary

All four precommitted bodies must be discovered by one unchanged learner, and every member of every
public equivalence class must pass every hidden case. A positive result supports bounded induction
of opaque command words in a generic finite word language. It does not establish arbitrary protocol
induction, independent target authorship, real-device competence, multimodal grounding or AGI.

M068 is noncanonical. The target-bank freeze commit is not a result and cannot be described as one.
