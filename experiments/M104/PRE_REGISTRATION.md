## 1. Reason for the successor

M103 attempt 1 is permanently negative under D072. Its unique runner produced a preserved result,
but the first frozen checker command exited before replay because direct script execution could not
resolve `scripts.run_m103_qualification`. P15 was uncomputed. M104 may not invoke M103's checker
again, materialize an M103 report or change any M103 protocol/result byte.

M104 tests whether the same scientific mechanism qualifies under a new experiment with a fresh
population and a corrected, pretested checker entry point. A positive M104 does not change D072.

## 2. Frozen scientific mechanism

The mechanism under test is the exact M103 mechanism:

- exact positive M102 U2 predecessor;

only bind a new pool/result namespace and repair the checker process bootstrap.

## 3. Fresh population rule

Before any M104 qualification execution, author and freeze one complete eleven-record,
sixteen-hidden-case population. It must use the same two carrier families and structural test but
reuse no M103 demand ID, case ID, world ID, context token, configuration section/option/value, path,
file content or hidden initial. It is a complete population, not a draw; no reroll, replacement or
post-result addition is permitted.

Qualification bytes remain absent from the S-prime producer capsule and enter isolated consumers
only after the same process-death boundaries as M103. Pool authoring may validate schema and action
semantics but may not run the complete acquisition experiment.

## 4. Checker correction

The M104 checker must own or import only the already-frozen independent M103 predicate semantics. It
must not import the M103 runtime or executor for predicate evaluation. For replay only it may import
the M104 orchestration runner after explicitly placing the repository root on `sys.path`.

Before protocol freeze, a subprocess test must launch the checker by its exact repository
direct-script path and execute an `--entrypoint-preflight` mode. That mode may bind files and import
the M104 runner but must not open the M104 qualification pool, result or report. A module-only test is
insufficient because it would repeat the M103 blind spot.

The canonical post-result checker command will be frozen explicitly. No alternative invocation is
allowed after the first checker attempt.

P1-P15 retain exactly the M103 scientific meaning. In particular:

The verdict is positive iff all fifteen predicates are computed and true. Any false or uncomputed

bounded constructor-reach evidence M103 failed to qualify. It would establish only that an acquired,
