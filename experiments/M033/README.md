# M033 — post-migration plasticity

M032 proved a bounded integration fact: an independently adopted executable rewrite can
be compiled after opaque-substrate discovery and transported together with its rewrite
passport, learned tools and declared learning state.

M033 asks the next, harder question:

> Does that transported state causally improve learning on a task family that did not
> exist before migration?

The experiment must distinguish a migrated intelligent process from a migrated output.
It therefore compares the complete M032 lineage against fresh, unchanged-parent,
output-only, learning-state-ablated and learned-tool-ablated controls under paired task
seeds and exact DFA ground truth.

No primary seed may be opened until the positive and negative controls pass and the
advantage rule is frozen. See [`PROTOCOL_DRAFT.md`](PROTOCOL_DRAFT.md) and
[`STATUS.md`](STATUS.md).
