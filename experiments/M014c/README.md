# M014c — Distribution-General Portable Plasticity

M014c addresses the exact failure discovered by M014b. M014b transported and executed a plasticity mechanism perfectly, but its learned prior did not retain a sealed query-efficiency advantage.

M014c replaces state-index edits and a static prior with:

- structural transformation programs expressed through graph roles rather than state IDs;
- a hierarchy over transformation families;
- integer-only online adaptation across a persistent sequence of episodes;
- a portable, deterministic decision trace;
- one discovered opaque substrate reused throughout each environment.

The development phase uses multiple source environments and larger held-out DFAs. Every scored episode must retain an ambiguous version space; trivial one-candidate tasks are rejected by the generator.

No canonical evaluation is allowed yet. Thresholds and the sealed profile generator will be frozen only after the full development benchmark and negative controls are complete.
