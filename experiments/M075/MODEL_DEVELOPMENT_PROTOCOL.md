This protocol compares the existing structured request with the same request augmented by M075's
audited epistemic state. It runs one independent `gpt-5.6-sol` sample per condition on each of the
six public M075 development tasks, in twelve fresh isolated containers and with four decisions at
most per episode.

The machine-readable commitment is
`ef024062d5fde3e385749153f471ef1dfc0c3bd664db859db88c78d70e94c899`. It binds the apparatus commit,

## Interpretation boundary

This is deliberately contaminated engineering evidence: the task bank is public and authored in
this repository; the two conditions use independent model samples; no provider snapshot, seed or
token accounting is available. Therefore this comparison cannot establish a causal effect, test
H21, qualify Genesis Gate 2 or support an AGI claim—regardless of its outcome.

Its only legitimate use is deciding whether the epistemic mechanism is promising enough to freeze
before an independently maintained, private, cross-domain evaluation. Every outcome, including a
fault or regression, must be preserved.
