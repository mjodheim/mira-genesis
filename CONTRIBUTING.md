# Contributing

## Attribution

Repository history and pull-request metadata must identify the responsible human
contributor without tool or vendor credit.

- A commit author, committer and optional co-author must be a human identity.
- Automated service accounts may run checks but must not create repository commits.
- Pull-request titles, descriptions and branch names describe the research change
  only; they do not advertise or credit development tools.
- Generated commit trailers or badges must be removed before publication.

The `Attribution policy` workflow checks every pull request against these rules.

## Language

All active repository communication is written in English. See
[`LANGUAGE_POLICY.md`](LANGUAGE_POLICY.md) for the historical-evidence exception.
